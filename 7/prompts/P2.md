# P2 prompts log

## Prompt 1: Understand P2 problem and decomposition strategy

> I am working on P2: Form a Valid Arithmetic Equation (file 7/code/7_q2.pl). Given a list of non-negative integers, we need to insert +, -, *, / and exactly one = between numbers (preserving order, with optional parentheses) so both sides have equal integer value. Division must be exact at every node and divisor non-zero. Canonical string format has specific precedence and left-associativity parenthesization rules. We must follow the decomposition rule: one unit of work per prompt. Can you explain the decomposition plan for P2?

## Prompt 2: Arithmetic evaluation helper (compute/4)

> Write only the compute/4 predicate for P2: compute(+Op, +A, +B, -Val) that evaluates arithmetic operations (+, -, *, /) on integer operands. Division is allowed only when it is exact (the result is an integer with no remainder) and the divisor is not zero. Sub-expression values may be negative, and all arithmetic must produce integer values.

## Prompt 3: Expression generator and evaluator (expr/3)

> Write only the expr/3 predicate for P2: expr(+Numbers, -Tree, -Value) that constructs and evaluates binary expression trees over a contiguous non-empty slice of non-negative integers. Tree is either num(N) for a single number or node(Op, Left, Right) for sub-expressions, and Value is the computed integer value.

## Prompt 4: Precedence table and canonical expression renderer (render/4)

> Write only the precedence/2 table and render/4 predicate for P2 that formats an expression tree into a canonical SWI-Prolog string without spaces, following the assignment rules: * and / bind tighter than + and -; operators are left-associative; a left operand is parenthesized only if its top operator has lower precedence than its parent; a right operand is parenthesized if its top operator has the same or lower precedence than its parent; a single number is never in parentheses.
