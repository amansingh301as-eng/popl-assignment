## Prompt 2: Inorder accumulator helper (inorder-acc)

> Write only the inorder-acc helper function for S1 that collects tree node values in inorder (left subtree, node, right subtree) into an accumulator list. It must not use the forbidden append built-in and must handle () as returning the accumulator.

## Prompt 3: Preorder accumulator helper (preorder-acc)

> Write only the preorder-acc helper function for S1 that collects tree node values in preorder (node, left subtree, right subtree) into an accumulator list without using the forbidden append built-in.

## Prompt 4: Postorder accumulator helper (postorder-acc)

> Write only the postorder-acc helper function for S1 that collects tree node values in postorder (left subtree, right subtree, node) into an accumulator list without using the forbidden append built-in.

## Prompt 5: Tree height helper (tree-height)

> Write only the tree-height helper function for S1. The height of () is 0, and the height of a node is 1 plus the larger of the heights of its two subtrees using the allowed max operator.

## Prompt 6: Tree leaves counter helper (tree-leaves)

> Write only the tree-leaves helper function for S1. A leaf is a node whose left and right subtrees are both (). The empty tree () has 0 leaves. An internal node has leaves equal to the sum of leaves of its left and right subtrees.
